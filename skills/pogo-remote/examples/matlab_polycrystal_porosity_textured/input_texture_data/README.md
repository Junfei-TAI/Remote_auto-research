# input_texture_data

Place paradigm-2 texture/microstructure inputs here, for example:

- `0SigX*.txt` orientation assignment files for POGO input generation
- `.ctf` files for MTEX/EBSD-based processing
- `grainId_*.txt` grain-label maps
- optional `porosity_map.mat` or related region/mask data

These are intentionally not committed as large or private research inputs.
